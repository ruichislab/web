# Política de Privacidad – RuichisLab Book Ranker

Última actualización: Septiembre de 2026

RuichisLab desarrolla la extensión para navegadores RuichisLab Book Ranker. Esta política describe con total transparencia el tratamiento de la información técnica al utilizar esta herramienta.

1. Operación 100% Local
RuichisLab Book Ranker funciona exclusivamente de manera local en el navegador del usuario. Todo el procesamiento de datos, cálculos matemáticos y análisis de elementos de la interfaz se ejecutan directamente en la memoria volátil del dispositivo local.
2. Datos del Usuario

* La extensión no recopila, no solicita, no almacena ni transmite ningún dato personal identificable (nombres, direcciones, correos electrónicos, identificadores de dispositivo o direcciones IP).
* La extensión no tiene acceso a cuentas de usuario, carritos de compra, información financiera ni contraseñas.
* No se rastrea el historial general de navegación ni la actividad fuera de las páginas de producto compatibles.

3. Datos de Catálogo Público
La herramienta únicamente analiza elementos públicos y visibles dentro del Document Object Model (DOM) de las fichas de producto de Amazon (como precio de lista, tamaño de archivo digital y clasificación de ventas BSR) con el único fin de calcular en tiempo real estimaciones de regalías netas y márgenes publicitarios. Ninguno de estos datos es transmitido a servidores remotos ni a bases de datos externas.
4. Permisos Técnicos

* activeTab: Se utiliza exclusivamente para ejecutar el script de análisis en la pestaña actual cuando el usuario visualiza una ficha de libro.
* storage: Se utiliza de manera local para persistir configuraciones visuales del usuario (como pestañas activas de la interfaz). No almacena información privada.
* Permisos de host: Limitados a los dominios públicos de Amazon para permitir la inyección de la interfaz gráfica y la lectura de los datos de producto expuestos.

5. Código Remoto
La extensión no descarga, no ejecuta ni enlaza código remoto ejecutable. Todo el código fuente está empaquetado de forma íntegra dentro de la extensión distribuida.
6. Contacto
Para dudas sobre el funcionamiento o la privacidad de esta herramienta, puede contactar a: contacto@ruichislab.com
